Had enough of slow transfer speeds, needing multiple apps, lack of online playback and centralized file management?
FileSent is a minimalist, high-speed, zero-traffic local area network file transfer tool. No data cables or cloud services required. Achieve ultra-fast cross-device and cross-platform file sharing between phones, computers, tablets and watches under the same WiFi/LAN.

Free:
- Install one app on a single device to enable cross-platform sharing across multiple devices
- Unlimited speed throughout transmission, direct connection without relay, making full use of LAN bandwidth
- Supports folder transfer, compatible with photos, videos, documents and all types of files
- Local LAN service for centralized file management; data is stored locally only and never uploaded to the cloud
- Built-in script injection protection to fully secure local access and data safety

Pro:
- Apple Watch Support:
  1. Transfer files/folders from iPhone to Watch, full file management on Watch including rename, move, delete, preview and playback
  2. Native local video playback
  3. Image preview supports left/right swipe to switch previous/next files in the same directory
  4. Text file preview with automatic reading scroll position memory. For text-to-speech, search and install EchoReadPro on app stores
  5. Audio playback supports pause, track switching, same-directory loop playback, and automatic saving of playback settings
- Stable high-speed transmission for extra-large files
- Built-in file compression and decompression
- Online preview for text, audio and video
- Online video playback with automatic loading of multiple subtitles in the same directory
- Synchronization of multiple clipboard entries
- Independent text file management

=FileSent - 简易快速共享
受够了传输速度慢、需要安装多个应用、无法在线播放或集中管理文件的问题吗？
FileSent 是一款极简、高速、零流量的局域网文件传输工具。无需数据线或云端，在同一 WiFi/局域网下即可实现手机、电脑、平板、手表之间的跨设备跨平台极速互传。

免费版：
- 在单设备安装一款应用，即可实现多设备跨平台共享
- 全程不限速，直连无中转，充分利用局域网带宽
- 支持文件夹传输，兼容照片、视频、文档等各类文件
- 局域网本地服务，集中管理文件，数据仅本地存储、不上云端
- 内置防脚本注入防护，全面守护本地访问与数据安全

专业版：
- Apple Watch支持:
  1. 支持 iPhone 向手表传输文件 / 文件夹，支持手表端文件管理，如重命名、移动、删除、预览、播放全操作
  2. 原生支持视频本地播放
  3. 图片预览支持左右滑动切换同级目录的上一张 / 下一张
  4. 文本文件预览，自动记忆阅读滚动位置。文本语音朗读可在各应用商店搜索安装 EchoReadPro
  5. 音频播放支持暂停、切歌、同目录循环播放，自动记忆播放设置
- 超大文件稳定高速传输
- 内置文件解压缩功能
- 支持文本、音频、视频在线预览
- 在线视频播放，自动加载同一目录下的多字幕
- 多剪贴板集合同步
- 独立文本文件管理

=FileSent - 簡単スピード共有
転送速度の遅さ、複数アプリのインストールが必要なこと、オンライン再生やファイルの集中管理に対応していない点にうんざりしていませんか？
FileSent はシンプルで高速、通信量を消費しないローカルネットワークファイル転送ツールです。データケーブルやクラウドサービスは不要。同一WiFi/ローカルネットワーク内で、スマホ、パソコン、タブレット、スマートウォッチ間で機器・プラットフォームをまたいだ高速ファイル送受信が可能です。

無料版：
- 1台の機器にアプリを1つインストールするだけで、複数機器間でクロスプラットフォーム共有を利用可能
- 転送速度に制限なし、中継なしの直接接続でローカルネットワークの帯域幅を最大限活用
- フォルダ転送に対応、写真、動画、ドキュメントなど各種ファイルに互換
- ローカルネットワーク上で動作しファイルを集中管理。データは端末内にのみ保存されクラウドへ送信されません
- スクリプトインジェクション防止機能を搭載し、ローカルアクセスとデータをしっかり保護

Pro版：
- Apple Watch対応：
  1. iPhoneから時計へファイル/フォルダ転送可能。時計側で名前変更、移動、削除、プレビュー、再生といったファイル管理を完全操作
  2. ネイティブでローカル動画再生に対応
  3. 画像プレビューで左右スワイプにより同一フォルダ内の前/次画像へ切り替え
  4. テキストファイルプレビュー時、スクロール位置を自動記憶。テキスト読み上げは各アプリストアでEchoReadProを検索しインストールしてください
  5. オーディオ再生は一時停止、曲送り、同一フォルダ内リピート再生に対応、再生設定を自動保存
- 大容量ファイルの安定高速転送
- ファイル圧縮・解凍機能内蔵
- テキスト、音声、動画のオンラインプレビュー
- オンライン動画再生時、同一フォルダ内の複数字幕を自動読み込み
- 複数クリップボード内容の同期
- 独立したテキストファイル管理機能
