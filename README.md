FileSent - Simple Fast Share
Tired of slow transfer speeds, needing to install multiple apps, and having no online playback or centralized file management?
FileSent is a minimalist, high-speed, zero-data LAN file transfer tool. No cables or cloud required. Transfer files instantly between phones, computers, and tablets on the same WiFi/LAN network.

Free:
- Install on one device for multi-device cross-platform sharing
- Unlimited speed, direct connection without relay, maximizing LAN bandwidth
- Support folder transfer for photos, videos, documents and all file types
- LAN local service, centralized file management, data stored locally only, no cloud upload
- Built-in script injection protection, fully safeguarding local access and data security

Pro:
- Stable high-speed transfer of ultra-large files
- Built-in file decompression
- Support online preview of text, audio, and video
- Online video playback, automatic loading of multiple subtitles from the same directory
- Multi-clipboard collection sync
- Independent text file management

=FileSent - 简易快速共享
受够了传输速度慢、需要安装多个应用、无法在线播放或集中管理文件的问题吗？
FileSent 是一款极简、高速、零流量的局域网文件传输工具。无需数据线或云端，在同一 WiFi/局域网下即可实现手机、电脑、平板之间的跨设备跨平台极速互传。

Free：
- 在单设备安装一款应用，即可实现多设备跨平台共享
- 全程不限速，直连无中转，充分利用局域网带宽
- 支持文件夹传输，兼容照片、视频、文档等各类文件
- 局域网本地服务，集中管理文件，数据仅本地存储、不上云端
- 内置防脚本注入防护，全面守护本地访问与数据安全

Pro：
- 超大文件稳定高速传输
- 内置文件解压缩功能
- 支持文本、音频、视频在线预览
- 在线视频播放，自动加载同一目录下的多字幕
- 多剪贴板集合同步
- 独立文本文件管理

=FileSent - 簡単スピード共有
転送速度の遅延、複数のアプリのインストール、オンライ再生や集中ファイル管理のないことに飽き飽きしていませんか？
FileSentは、データ使用量ゼロのミニマルで高速なLANファイル転送ツールです。ケーブルやクラウドは不要です。同じWiFi/LANネットワーク上で、スマホ、电脑、タブレット間でファイルを瞬時に転送できます。

Free:
- 1つのデバイスにインストールして、複数のデバイスとプラットフォームで共有
- 速度制限なし、中継なしの直接接続、LAN帯域幅を最大活用
- 写真、動画、ドキュメントなどすべてのファイル形式のフォルダ転送をサポート
- LANローカルサービス、集中ファイル管理、データはローカルにのみ保存、クラウドにアップロードしない
- ビルトインスクリプトインジェクション保護、ローカルアクセスとデータセキュリティを完全に保護

Pro:
- 超大型ファイルの安定した高速転送
- 内蔵ファイル解凍機能
- テキスト、オーディオ、视频のオンラインプレビューをサポート
- 同じフォルダからの複数の字幕の自動読み込みによるオンライン動画再生
- 複数のクリップボードコレクションの同期
-  독립적인テキストファイル 관리
